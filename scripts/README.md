# Как добавлять и менять главы

Теперь HTML-страницы в корне — это сгенерированный результат для GitHub Pages. Их не нужно редактировать вручную.

## Что редактировать

- `content/chapters.json` — порядок глав и метаданные: файл, номер, `<title>`, заголовок в шапке, том, кандзи и подзаголовок.
- `content/chapters/*.html` — только содержимое главы внутри `<main id="main-content">`.
- `templates/chapter.html` — общая структура страницы главы.
- `templates/index.html` — общая структура оглавления.
- `assets/` — общие стили и скрипты сайта.

## Добавить новую главу

1. Создайте новый файл с текстом, например `content/chapters/10-29.html`.
2. Добавьте объект для этой главы в `content/chapters.json` и задайте ему следующий `order`.
3. Запустите генератор:

```bash
python3 scripts/build.py
```

Генератор сам обновит `10-29.html`, `index.html` и ссылки «предыдущая / следующая».
