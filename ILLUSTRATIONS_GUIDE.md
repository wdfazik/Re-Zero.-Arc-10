# Как добавить иллюстрацию в главу

После рефакторинга тексты глав хранятся в Markdown-разметке в `data/chapters/*.js` без единого HTML-тега. Никакие `<style>`-блоки или теги `<figure>` больше копировать не нужно — стили и адаптивная вёрстка подключены глобально.

## 1. Откройте нужную главу

Откройте файл главы, например `data/chapters/10-46.js`.

## 2. Вставьте строку с иллюстрацией

Внутри шаблона текста между нужными абзацами добавьте **одну строку** в стандартном синтаксисе Markdown:

```markdown
![Краткое описание сцены](https://example.com/image.jpg)
```

- Текст в квадратных скобках `[...]` используется как `alt`-описание (для доступности и если картинка не загрузится).
- В круглых скобках `(...)` укажите прямую `https://` ссылку или локальный путь (например, `./assets/illustrations/10-46-scene1.webp`).

> **Рекомендация:** вместо временных внешних ссылок VK (`sun9-*.userapi.com`) надёжнее хранить оптимизированные изображения (`.webp`/`.jpg`) прямо в репозитории в `assets/illustrations/`, чтобы они не пропали со временем.

## 3. Проверьте результат

1. Проверьте синтаксис валидатором:
   ```bash
   python scripts/validate.py
   ```
2. Откройте `index.html` напрямую в браузере (или через `python -m http.server 8000`) и перейдите к нужной главе.

## Пример

```markdown
Текст абзаца, после которого нужна иллюстрация.

![Круш срывает повязку, обнажая Глаз](https://example.com/image.jpg)

Следующий абзац главы.
```
