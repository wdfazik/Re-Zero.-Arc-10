# Как вручную добавить иллюстрации в главы

Этот репозиторий хранит главы как отдельные HTML-файлы. Чтобы добавить иллюстрацию в любую главу вручную, повторите шаги ниже.

## 1. Найдите место для вставки

1. Откройте HTML-файл нужной главы, например `10-18.html`.
2. Найдите строку или абзац, после которого должна появиться иллюстрация.
3. Вставляйте иллюстрацию после закрывающего тега соответствующего блока или абзаца:
   - после `</p>`, если место — обычный абзац;
   - после `</div>`, если абзац находится внутри декоративного блока вроде `moment`.

## 2. Добавьте стили, если их ещё нет в файле

Внутри тега `<style>` добавьте один раз на файл блок стилей:

```css
/* ── Chapter illustrations ── */
.chapter-illustration {
  margin: 2.4em auto;
  text-align: center;
}

.chapter-illustration img {
  display: block;
  width: min(100%, 720px);
  height: auto;
  margin: 0 auto;
  border-radius: 16px;
  box-shadow: 0 18px 42px rgba(0, 0, 0, 0.36);
}
```

Если в главе уже есть эти стили, повторно добавлять их не нужно.

## 3. Вставьте HTML иллюстрации

После нужного абзаца или блока вставьте:

```html
<figure class="chapter-illustration reveal">
  <img src="ССЫЛКА_НА_ИЗОБРАЖЕНИЕ" alt="Краткое описание иллюстрации" loading="lazy">
</figure>
```

Что заменить:

- `ССЫЛКА_НА_ИЗОБРАЖЕНИЕ` — прямая ссылка на картинку.
- `Краткое описание иллюстрации` — понятное описание сцены для доступности и случаев, когда изображение не загрузится.

Класс `reveal` подключает существующую анимацию появления главы. Если иллюстрация должна отображаться сразу без анимации, уберите `reveal`.

## 4. Проверьте результат

1. Откройте HTML-файл в браузере.
2. Убедитесь, что картинка появляется в правильном месте.
3. Проверьте страницу на узком экране или через режим адаптивной вёрстки: изображение должно сжиматься до ширины текста и не выходить за экран.
4. Если картинка слишком большая или маленькая, измените `720px` в строке `width: min(100%, 720px);`.

## 5. Повторите для остальных глав

Для каждой следующей главы:

1. Откройте нужный HTML-файл.
2. Если стилей `.chapter-illustration` в нём ещё нет — добавьте их один раз.
3. Найдите место вставки.
4. Добавьте блок `<figure class="chapter-illustration reveal">...</figure>` с новой ссылкой и новым `alt`.
5. Проверьте страницу в браузере.

## Пример

```html
<p class="narr reveal">Текст абзаца, после которого нужна иллюстрация.</p>

<figure class="chapter-illustration reveal">
  <img src="https://example.com/image.jpg" alt="Иллюстрация: описание сцены" loading="lazy">
</figure>

<p class="narr reveal">Следующий абзац главы.</p>
```
