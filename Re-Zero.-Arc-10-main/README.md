# Re:Zero — Арка 10 · «Страна Короля Льва»

Статический сайт-читалка 10-й арки *Re:Zero* для GitHub Pages (`re-zero-10-arc.ru`) на базе единого SPA-приложения и ленивой подгрузки глав с разметкой Markdown — **без отдельных HTML-файлов на каждую главу, без этапа сборки и с полноценной работой даже при прямом открытии `index.html` с диска (`file:///`)**.

## Структура проекта

```text
├── index.html                 # Единое приложение (оглавление + читалка)
├── 404.html                   # Авто-редирект старых ссылок (/10-45.html -> /?chapter=10-45)
├── data/
│   ├── manifest.js            # Единый каталог арки: фазы, тома, метаданные всех глав
│   ├── glossary.json          # Словарь автоподсветки терминов для import_chapter.py
│   └── chapters/
│       └── 10-*.js            # Тексты глав в Markdown-разметке (без HTML-тегов, грузятся по требованию)
├── assets/
│   ├── site.css               # Единая таблица стилей (~35 КБ вместо 350 КБ) с поддержкой light/dark
│   ├── app.js                 # Маршрутизатор (?chapter=... / #chapter=...), оглавление, поиск, кеш и предзагрузка
│   ├── markdown-renderer.js   # Безопасный DOM-рендерер Markdown (0 вызовов innerHTML)
│   ├── settings.js            # Тема, настройки шрифта/ширины/выравнивания, ленивая загрузка шрифтов
│   └── effects.js             # Прогресс чтения, reveal-анимации, адаптивный Canvas
├── scripts/
│   ├── import_chapter.py      # Импорт нового .txt файла в data/chapters/<id>.js + data/manifest.js
│   └── validate.py            # Проверка целостности каталога и синтаксиса всех глав
├── ILLUSTRATIONS_GUIDE.md     # Инструкция по добавлению иллюстраций
└── CODE_REVIEW.md             # Полный отчёт Code-Review и список изменений
```

## Как добавить новую главу

Сборка больше **не требуется** — GitHub Pages публикует изменения напрямую, а локально достаточно просто открыть `index.html`.

### Способ 1: через скрипт из `.txt` (с автоподсветкой терминов)
```bash
python scripts/import_chapter.py 10-47.txt --id 10-47 --number "Глава 47" --volume "Том 47" --phase phase-4 --location "Летающий замок Кугельшрайбер"
python scripts/validate.py
```

Скрипт автоматически подсветит повторяющиеся термины 10-й арки (`Любимые Дети`, `Проклятая Печать`, `Таинство`, `Глаз Дракона`, `Шесть Языков`, `Драконий Меч Рейд`, `Культ Ведьмы`, `Королевские Выборы` и др. во всех падежах) по словарю `data/glossary.json`. Словарь можно свободно дополнять, а отключить автоподсветку — флагом `--no-glossary`. После импорта остаётся при желании обернуть 2–3 кульминационных абзаца в `:::moment shock` и вставить иллюстрации строкой `![Описание](URL)`.

### Способ 2: вручную
1. Создайте файл `data/chapters/10-47.js` с текстом главы:
   ```js
   window.REZERO_REGISTER_CHAPTER('10-47', `
   @location Летающий замок Кугельшрайбер

   Текст первого абзаца...
   `);
   ```
2. Добавьте объект главы в массив `"chapters"` в `data/manifest.js`.
3. Проверьте корректность:
   ```bash
   python scripts/validate.py
   ```

## Разметка Markdown для глав

- Обычные абзацы — просто текст, разделённый пустой строкой.
- Локация: `@location Летающий замок Кугельшрайбер`
- Разделитель сцен: `---`
- Мысль персонажа: `> «Нет… не время».`
- Курсивный абзац: `@italic Текст...`
- Иллюстрация: `![Описание сцены](https://example.com/image.jpg)`
- Эмоциональный блок (`shock`, `anger`, `resolve`, `heavy`, `warmth`, `krusch`, `battle`):
  ```markdown
  :::moment shock
  Текст кульминационного момента...
  :::
  ```
- Примечание переводчика:
  ```markdown
  :::note Минутка японского от Энди
  Текст примечания...
  :::
  ```
- Выделение терминов внутри строки: `{cult:Любимые Дети}`, `{dragon:Таинство}`, `{kingdom:Церковь}`, `{tongues:Шесть Языков}`, `{six-tongues:Шесть Языков}`, `{sword:Драконий Меч Рейд}`, `{lust:Архиепископ Похоти}`, `{sloth:Архиепископ Лени}`, `{gluttony:Архиепископ Чревоугодия}`.

Блок «Конец главы» и кнопки «Предыдущая / Оглавление / Следующая» генерируются автоматически.

## Локальный просмотр

- **Прямой запуск:** просто откройте `index.html` двойным кликом в браузере (используется `#chapter=...` без CORS-ограничений).
- **Через HTTP-сервер** (как на GitHub Pages с `?chapter=...`):
  ```bash
  python -m http.server 8000
  ```
  и откройте `http://localhost:8000/`.
